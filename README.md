# WA Smart Toolkit Legal Pages

This ZIP contains static HTML pages suitable for publishing with GitHub Pages.

## Files
- `index.html` — Privacy Policy
- `terms.html` — Terms & Conditions
- `disclaimer.html` — Disclaimer

## Publish
1. Create a public GitHub repository, e.g. `wa-smart-toolkit-legal`.
2. Upload all three HTML files to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish.

If your GitHub username is `YOUR-USERNAME`, the URLs will usually be:
- `https://YOUR-USERNAME.github.io/wa-smart-toolkit-legal/`
- `https://YOUR-USERNAME.github.io/wa-smart-toolkit-legal/terms.html`
- `https://YOUR-USERNAME.github.io/wa-smart-toolkit-legal/disclaimer.html`

These are examples only until your repository is published.

## Before publishing
- Confirm all statements match the actual released app and its SDKs.
- Confirm `blogbai2@gmail.com` is the correct privacy contact.
- Review the Google Play Data safety form and the advertising SDK's actual data practices.
- Update the effective date if needed.
- These templates are general information, not legal advice or a certification of compliance.
- No separate Ads Consent Policy is included. The Privacy Policy includes advertising data disclosures; any AdMob/UMP consent message and settings are configured separately in the relevant Google tools.
